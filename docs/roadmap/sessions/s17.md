  вызывает), но **гейт был красный 7/7 прогонов** — см. **F48**. Причина: PEP 639 (SPDX-выражение S14/F19 +
  классификатор `License :: *` → `pip install -e ".[dev]"` падал на всех джобах за 12 с) и fail-closed
  gitleaks-action без платной лицензии. Репро локально (setuptools 81 = раннер), фикс проверен: классификатор
  убран → `Would install`; gitleaks = пиннутый бинарь v8.30.1, `git .`-скан 56 коммитов → 0 утечек.
- **Урок в реестр:** «воркстрим закрыт» для CI подтверждается `gh run list`, а не фактом коммита воркфлоу.
- **F49 🔴 — первый живой прогон гейта сразу окупился:** `.gitignore` `workspace/` без ведущего слэша
  утаскивал в игнор `config/templates/workspace/` ⇒ **6 шаблонов структуры никогда не были в git**, на
  чистом клоне `structure_create` падал `TemplateError: Шаблон не найден: niche`. Якорь `/workspace/` +
  шаблоны закоммичены. Локально этот класс не ловится в принципе.

### Сессия 17 (доп. 4) — директива владельца: фаза ТАБЛИЦЫ на сервере, не в руках клиента

**Владелец (в ответ на вопрос про шаг 4): «нужно все три»** + принцип: *всё делает скрипт, а не ИИ; Клоду
нужно лишь передать имя или имена*. Правка дизайна: шаг 2 требовал, чтобы клиент вернул серверу его же
`tables_pending` — убрано, `structure_create` материализует книги сам. Книги создаются только у реально
созданных сущностей (канал создан ≠ видео-проект есть → книг видео нет), без декларации — честно отложены.
`structure_materialize_tables` остался догоняющим. `TableMaterialized` заведён в `KNOWN_FACT_TYPES` (D25).
Пруф §7: «сетка + канал + 20 конкурентов» одним вызовом → книг на диске ровно столько, сколько отчитано.
