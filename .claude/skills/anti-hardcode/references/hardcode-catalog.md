# Каталог хардкода — grep-рецепты и эталоны выноса

> Разворачивает 6 типов из `SKILL.md`. Для каждого: как найти, эталон выноса из проекта, что НЕ трогать.

---

## Тип 1 — Per-entity ветки (🔴)

**Найти:**
```bash
grep -rnE "if .*\b(type|entity|table|kind|name)\b.*==\s*[\"']" core/ server.py tools/
grep -rnE "==\s*[\"'](video|channel|niche|network|competitor)[\"']" core/ server.py
```
**Анти-паттерн:** `if type == "video": create_video_stuff() elif type == "channel": ...` — движок разбирает имя и ветвится.

**Эталон проекта (так правильно):** словари-данные вместо веток —
```python
TYPE_PREFIX = {"video": "VID", "channel": "CH", ...}
ROOT_CONTAINER = {"niche": "niches/"}
REQUIRED_PARENT_TYPE = {"competitor_channel": "channel"}
```
Новая сущность = запись в словаре/новый `*.tpl.yaml`, а не новая ветка. Если логика реально различается по типу — она едет из шаблона/декларации (`config/templates/*`, `config/*.yaml`), а не из `if`.

**Не трогать:** ветку по типу в **фабрике-регистраторе**, которая как раз строит словарь (одноразовая проводка), — это не спагетти-спец-случай.

## Тип 2 — Магические литералы (🟠)

**Найти:**
```bash
grep -rnE "[\"'][^\"']*/[^\"']*[\"']" core/ server.py        # пути
grep -rnE "\b[0-9]{2,}\b" core/firewall/ core/transport/     # числа-пороги/порты/таймауты
grep -rnE "[\"'](META|SCENES|PERFORMANCE)[\"']" core/         # имена листов
```
**Куда:** пути/имена → `config/*.yaml` или константа модуля; пороги firewall → `config/firewall.yaml`; имена листов → шаблон таблицы (`config/templates/tables/*`); enum-значения → реестр/`Literal` (это уже стык с `code-quality` G15).

**Эталон:** `_atomic_write_json` путь реестра собирается от `workspace`, префиксы — из `TYPE_PREFIX`. **Анти-эталон (deferred hook):** `stt device="cuda"` захардкожен — должно быть конфигурируемо.

**Не трогать:** единичный локальный литерал без второго использования и без причины меняться (напр. `"META"` как имя дефолт-листа, если оно одно и в одном месте) — вынос ради выноса плодит конфиг-ад. Критерий — «кто-то захочет менять это без правки кода?».

---

## Тип 3 — Config-is-ignored (🔴, D2) — самый коварный

Значение **уже** в `config/*.yaml`, но код держит собственное и конфиг не читает. Выглядит настроенным, а на деле хардкод.

**Найти:** для каждого ключа в `config/firewall.yaml`/`server_reactions.yaml`/`channel_config.yaml` — `grep` его имени в коде: читается ли? 
```bash
# пример: ключ есть в конфиге, но 0 обращений в коде = игнорируется
grep -rn "max_requests_per_minute\|ban_after_violations" core/
```
**Эмпирика (обязательна):** правишь значение в YAML → поведение меняется? Нет → D2, конфиг мёртв.

**Лечение:** реально грузить (`config.get(...)` с дефолтом), проверить hot-reload там, где он есть (memory `config-hot-reload`).

## Тип 4 — Захардкоженные секреты (🔴, D31)

**Найти:**
```bash
grep -rnE "(token|secret|key|password|cred)\s*=\s*[\"'][^\"']+[\"']" core/ server.py
gitleaks detect --source=.
```
Токен туннеля, ключи провайдеров, креды. → env/секрет-хранилище; дефолт — пустой, не реальный секрет. **Эскалировать в `security-reviewer`** (D31 — inline-comment баг .gitignore однажды раскрыл tunnel.yaml).

**Не трогать:** имена переменных окружения (`"TUNNEL_TOKEN"` как ключ `os.environ` — это не секрет, а его адрес).

---

## Тип 5 — Дефолт-вместо-конфигурации (🟡)

Жёсткое значение, которое кто-то захочет настраивать. Эталон-исправление проекта: `DEFAULT_DANGEROUS_TOOLS` из захардкоженного множества стал `__init__(dangerous_tools=None)` с дефолтом-frozenset. Паттерн: `def __init__(self, X=None): self.X = X if X is not None else DEFAULT_X`.

**Критерий:** значение — политика/настройка (список опасных инструментов, пороги, лимиты) → параметр+конфиг с дефолтом. Значение — инвариант реализации (версия протокола) → константа, не конфиг.

---

## Тип 6 — Дублированный литерал (🟡)

Один путь/имя/префикс в нескольких местах → рассинхрон при правке.
**Найти:** `grep -rn "workspace/" core/ server.py | wc -l` — сколько независимых вхождений одного пути?
**Лечение:** единая константа/один источник (напр. `WORKSPACE_PATH`), остальные ссылаются.

---

## Общий алгоритм выноса (безопасно)

1. Найди все вхождения значения (`grep`), убедись, что смысл один.
2. Заведи источник: ключ в подходящем `config/*.yaml` / шаблоне / именованную константу / параметр с дефолтом.
3. **Дефолт = прежнее значение** → поведение при пустом конфиге неизменно.
4. Проведи загрузку; **эмпирически** проверь, что правка источника меняет поведение (иначе ты сделал D2).
5. `tests/quick/` зелёные до и после. Решение→факт в историю.
