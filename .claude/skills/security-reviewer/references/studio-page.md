# Своя страница студии — угрозы разметки, сборки и внешних получателей

Транспорт (CORS, `Origin`, DNS-rebinding, CSRF, сессия) разобран в `browser-threats.md`. Здесь —
то, что появилось вместе со СВОЕЙ разметкой: страница исполняет данные, собирается чужими пакетами
и сама ходит к третьим лицам. Каждая строка проверяется запросом, грепом собранного дерева или
прогоном в браузере — рассуждение «нам не грозит» без этого не принимается.

Оглавление: данные в разметке · ссылки и адреса · внешние получатели · секреты в бандле ·
хранилище · заголовки страницы · сборка и сервер разработки · выгрузки · окна и фреймы.

## Данные в разметке

- Текст из данных — только детьми JSX (React экранирует). `dangerouslySetInnerHTML` на данных из
  `workspace/` или от провайдеров — находка по умолчанию; нужен форматированный текст — разбор в
  дерево элементов, а не строка HTML.
- Особо недоверенные — данные конкурентов: заголовки, описания, комментарии написаны
  посторонними людьми и приезжают через наш сервер, то есть выглядят «своими».
- Сообщение об отказе не показывает стек, внутренний путь или сырой ответ провайдера — только код
  реакции и рецепт; санитайзер отказа на сервере уже есть, UI не добавляет своего «подробнее».

## Ссылки и адреса из данных

- `href`/`src`, собранные из данных, проходят разбор `new URL()` и список разрешённых схем
  (`https:`; `mailto:` — если нужен). Запрет по списку плохих (`javascript:`) обходится регистром,
  пробелами и кодированием — поэтому список ХОРОШИХ.
- Ссылка наружу с `target="_blank"` — с `rel="noopener noreferrer"`: без `noreferrer` чужой сайт
  получает адрес нашего экрана (а в нём идентификаторы проекта и канала).

## Внешние получатели

Любой запрос страницы к чужому хосту — это адрес, время и `Referer` человека у третьего лица.
Условие владельца (план студии §4а): внешнего получателя данных без отдельного решения нет.

- Картинки по чужим адресам (стоковые фото в дизайне), шрифты с CDN, счётчики, сторонние скрипты —
  каждое снимается либо становится решением владельца с записью.
- Миниатюры YouTube конкурентов — тоже внешний получатель; лучше проксировать через свой сервер
  или хранить копию, чем раскрывать активность студии.
- Проверка — список хостов, к которым страница реально ходит (вкладка сети или
  `page.on("request")` в Playwright), против объявленного `connect-src`/`img-src`.

## Секреты в бандле

Всё, что попало в сборку, публично: `define: { "process.env.X": ... }`, `import.meta.env.VITE_*`,
строка в коде. В переданном дизайне ключ Gemini уезжал в бандл именно через `define` — снят при
переносе. Проверка — грепом СОБРАННОГО дерева, а не исходников: ключ мог приехать из переменной
окружения сборки.

```bash
npm --prefix studio run build
grep -rEn "AIza[0-9A-Za-z_-]{20,}|sk-[A-Za-z0-9]{20,}|ghp_[A-Za-z0-9]{20,}" studio/dist
```

`gitleaks` в CI смотрит репозиторий, а не `dist/`: ключ из окружения сборки он не увидит.

## Хранилище браузера

- Токен доступа к серверу в `localStorage`/`sessionStorage` читает любой пропущенный XSS. Сессия —
  cookie от сервера с `HttpOnly`, `Secure`, `SameSite=Strict`; как студия предъявляет себя серверу —
  открытое решение (раздел «Студия»), а не деталь реализации.
- `localStorage` — только удобства (открытая вкладка, фильтр), и страница работает без него.

## Заголовки страницы

Кроме CSP (раздел «Студия»): `X-Content-Type-Options: nosniff`, `Referrer-Policy:
strict-origin-when-cross-origin` (или `no-referrer`), `Permissions-Policy` с выключенными камерой,
микрофоном и геолокацией, `Cross-Origin-Opener-Policy: same-origin`, HSTS при HTTPS. Trusted Types
(`require-trusted-types-for 'script'`) — сильная защита от DOM-XSS, но только в Chromium: как
дополнительный слой, не как замена экранированию. Проверка — заголовки ответа на `index.html`
запросом, а не чтением конфига.

## Сборка и сервер разработки

- Сервер разработки Vite — не для сети: `host: "0.0.0.0"` (как в переданном дизайне) отдаёт
  исходники и файлы проекта всем в сети; у сервера разработки были уязвимости обхода
  `server.fs.deny`. Наружу — только собранное дерево, сервер разработки — на `localhost`.
- Карты исходников в продакшене не публикуются (`build.sourcemap` выключен или `hidden`).
- Поставка npm и её скрипты установки — `dependency-hygiene`.

## Выгрузки

Выгрузка таблицы в CSV: ячейка, начинающаяся с `=`, `+`, `-`, `@`, табуляции или возврата каретки,
исполнится формулой в табличном редакторе (CSV injection) — экранировать апострофом. Данные
конкурентов делают это реальным, а не теоретическим.

## Окна и фреймы

- `postMessage`: получатель проверяет `event.origin` по точному списку, отправитель не пишет `"*"`
  адресатом.
- Превью в `<iframe>` (если появится) — `sandbox` без пары `allow-scripts` + `allow-same-origin`:
  вместе они снимают песочницу целиком.
- Страницу студии не встраивает чужой сайт: `frame-ancestors 'none'` (раздел «Студия»).
