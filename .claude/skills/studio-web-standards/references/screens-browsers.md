# Экраны и браузеры

Оглавление: матрица ширин · раскладка · касание и наведение · высота экрана · модалки и таблицы на
телефоне · пол браузеров · движки и их причуды · видео в браузере · как гонять матрицу.

## Матрица ширин

| Ширина | Кто это | Что ломается первым |
|---|---|---|
| 320 | узкий телефон; нижний край WCAG 1.4.10 (перекладка без горизонтальной прокрутки) | длинные имена каналов, ряд кнопок, таблицы |
| 390 | типичный телефон | модалки, крошки навигации |
| 768 | планшет стоя | сетка карточек переходит на две колонки |
| 1024 | планшет лёжа, малый ноутбук | боковая панель + содержимое |
| 1280 | ноутбук | основной экран дизайна |
| 1920 | монитор | пустота по краям: `max-width` контейнера, строки текста не шире ~75 знаков <!-- снимок ок: типографское правило длины строки, не замер --> |

Плюс высота: телефон лёжа (низкий экран) — модалка обязана прокручиваться внутри себя, а
кнопка «Сохранить» не уезжает за край. Масштаб 200% в браузере равен ширине в два раза меньше —
отдельно проверять не нужно, если пройдена матрица.

## Раскладка

- **Mobile-first.** Класс без префикса — для узкого экрана; `sm:`/`md:`/`lg:`/`xl:` добавляют.
  Точки перелома — токены Tailwind (`--breakpoint-*` в `@theme`), не `[...px]` в разметке.
- **Контейнер важнее окна** для компонента, который живёт в разных местах: `@container` у родителя
  и `@sm:`/`@md:` у детей. Карточка в выдвижной панели и в сетке тогда одна и та же.
- **Флекс и сетка с длинным текстом**: ребёнок флекса по умолчанию не ужимается уже своего
  содержимого (`min-width: auto`) — длинное имя канала выталкивает соседей за край. `min-w-0` на
  ребёнке и `break-words`/`truncate` на тексте; у усечённого текста полное значение доступно
  (`title` или раскрытие).
- **Размеры шрифта растут ступенями токенов**, а не плавают `vw`: текст в `vw` не масштабируется
  браузерным зумом (нарушение WCAG 1.4.4). Если нужна плавность — `clamp()` с `rem`, объявленный
  токеном.

## Касание и наведение

- В Tailwind v4 `hover:` срабатывает только при `(hover: hover)`. Действие, появляющееся по
  наведению (кнопка «удалить» на карточке), на телефоне и планшете недоступно ВОВСЕ. У каждого
  такого действия — постоянный путь: меню «ещё», видимая кнопка на узкой ширине.
- Цель касания — не меньше 24×24 CSS px (WCAG 2.2, 2.5.8, AA); удобная — 44×44 <!-- снимок ок: внешние пороги WCAG 2.5.8 и Apple HIG -->.
  Маленькая иконка получает поле касания через `padding` или псевдоэлемент, а не увеличение значка.
- Жесты перетаскивания (таблицы, будущий таймлайн) — Pointer Events с `setPointerCapture` и
  `touch-action: none` на перетаскиваемом; HTML5 drag-and-drop на сенсорных экранах работает
  плохо. Запись — по отпусканию (домен `студия-общее`, Об2).

## Высота экрана

- `h-screen`/`100vh` на телефоне выше видимой области (панель браузера): `min-h-dvh`/`h-dvh`.
- Вырез и скругления экрана — `env(safe-area-inset-*)` при `viewport-fit=cover` в `<meta viewport>`.
- Фиксированная нижняя панель не перекрывает поле ввода, когда открыта клавиатура.

## Модалки и таблицы на телефоне

- Модалка на узкой ширине — на весь экран, прокрутка внутри, `overscroll-behavior: contain`, чтобы
  прокрутка не утекала на страницу под ней.
- Таблица шире экрана прокручивается в СВОЁМ контейнере с видимым намёком на продолжение, первый
  столбец закреплён (`sticky`); страница целиком горизонтально не прокручивается.
- Поле ввода на iOS с кеглем меньше 16 px <!-- снимок ок: внешнее поведение Safari iOS --> вызывает автоматический
  зум страницы — кегль полей не мельче этого.

## Пол браузеров — объявляется один раз

Tailwind v4 опирается на `@property`, каскадные слои и `color-mix()`, поэтому сам задаёт пол:
Safari 16.4, Chrome 111, Firefox 128 <!-- снимок ок: внешний порог, tailwindcss.com/docs/compatibility -->.
Цель сборки Vite по умолчанию (`baseline-widely-available`) ниже — значит действует тайлвиндовский
пол, и остальные инструменты обязаны знать именно его:

| Где | Что объявить |
|---|---|
| `package.json` → `browserslist` | тот же пол строкой запроса |
| `vite.config.ts` → `build.target` | те же версии движков |
| `tsconfig.json` → `lib`/`target` | не новее, чем держит пол (ES2022 сейчас совпадает) |
| `eslint` → `eslint-plugin-compat` (MIT) | читает `browserslist` и красит API выше пола |

Без линтера совместимости API выше пола (`Object.groupBy`, `Promise.withResolvers`, атрибут
`popover`) проходит `tsc` и падает у пользователя в Safari. Новое за пределами пола — только как
прогрессивное улучшение с проверкой `CSS.supports` или наличия функции, и экран обязан работать
без него.

Справка о поддержке — `caniuse.com` и статус Baseline на MDN; «я помню, что это уже везде» —
не справка.

## Движки и их причуды

Три движка, и все три обязательны: Chromium (Chrome, Edge, Яндекс Браузер, Opera), WebKit (Safari
на macOS и все браузеры iOS), Gecko (Firefox).

| Место | Причуда | Что делать |
|---|---|---|
| WebKit, macOS | клик по кнопке не даёт ей фокус | логика «закрыть по потере фокуса» проверяется в Safari, а не только в Chrome |
| WebKit, iOS | зум на поле мельче 16 px, `100vh` | см. выше |
| WebKit | `backdrop-filter` старых версий — с префиксом | префиксы расставляет сборка CSS по `browserslist`, руками не пишем |
| Gecko | полосы прокрутки: `scrollbar-width`/`scrollbar-color`, а не `::-webkit-scrollbar` | тёмная тема: `color-scheme: dark` на корне — родные контролы и полосы темнеют во всех движках |
| все | `<input type="date">` выглядит по-разному | формат даты в интерфейсе — `Intl.DateTimeFormat`, выбор даты — один компонент |
| все | вывод `Intl.NumberFormat` (компактная запись) слегка разный | тест не сравнивает отформатированную строку одного движка побайтно |
| все | буфер обмена — только в защищённом контексте и в том же жесте | запись в буфер — прямо в обработчике нажатия |

## Видео в браузере

Превью готового видео и будущий монтаж идут в `<video>`. Универсально воспроизводится MP4
(H.264 + AAC); WebM/VP9 и HEVC поддерживаются не везде. Встроенное воспроизведение на iOS —
`playsinline`; автозапуск — только `muted`. Формат превью, который отдаёт сервер, выбирается под
пол браузеров, а не под то, что удобно ffmpeg.

## Как гонять матрицу

Приём тот же, что у геометрии в `tests/studio_emulation/geometry.spec.ts`: проверки по
`[data-component]`, собранное дерево через `vite preview`. Матрица — проектами Playwright:

```ts
// playwright.config.ts — форма, а не готовая настройка
projects: [
  { name: "chromium-390", use: { ...devices["Pixel 7"] } },
  { name: "webkit-390", use: { ...devices["iPhone 14"] } },
  { name: "chromium-1280", use: { browserName: "chromium", viewport: { width: 1280, height: 800 } } },
  { name: "firefox-1280", use: { browserName: "firefox", viewport: { width: 1280, height: 800 } } },
  { name: "webkit-1280", use: { browserName: "webkit", viewport: { width: 1280, height: 800 } } },
],
```

WebKit в Playwright близок к Safari, но не равен ему — последнее слово за настоящим Safari на
устройстве перед выпуском. В этой среде предустановлен только Chromium; движки WebKit и Gecko
ставит CI, а не сессия.
