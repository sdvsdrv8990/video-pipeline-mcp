# Доступность студии — WCAG 2.2 AA

Оглавление: зачем в рабочем приложении · семантика · клавиатура и фокус · шаблоны виджетов ·
цвет и контраст · формы · динамика и статус · движение · графики · как проверять.

## Зачем это в рабочем приложении

Доступность — не только скринридер. Клавиатурой быстрее работает опытный пользователь, контраст
нужен на плохом мониторе и на солнце, крупный текст — на ноутбуке с масштабом 150%. И это
требование закона на ряде рынков (Европейский акт о доступности действует с июня 2025).
Норма проекта — WCAG 2.2 уровня AA; номера критериев ниже — для поиска в спецификации.

## Семантика — сначала правильный элемент

- **Действие — `<button type="button">`, переход — `<a href>`.** Переход ссылкой даёт «открыть в
  новой вкладке» и адрес (домен навигации, Нв1). `div`/`span` с `onClick` недоступен с клавиатуры
  и невидим скринридеру (2.1.1, 4.1.2).
- Ориентиры страницы: `header`, `nav`, `main`; заголовки по уровню без пропусков — по ним
  скринридер перемещается, как глаз по крупному шрифту (1.3.1, 2.4.6).
- Список карточек — список (`ul`/`li`), таблица данных — `table` с `th`, а не сетка `div`.
- `lang="ru"` на `<html>` (3.1.1) — иначе русский текст читается английским голосом.

## Клавиатура и фокус

- До каждого действия можно дойти `Tab` и выполнить `Enter`/`Space` (2.1.1); ловушек фокуса нет,
  кроме модалки, которая отпускает по `Escape` (2.1.2).
- **Фокус виден всегда** (2.4.7) и не спрятан под липкой шапкой (2.4.11). `outline-none` без
  `focus-visible:ring-*` — удалённый фокус. Кольцо фокуса — токен, одно на всё приложение.
- Порядок фокуса совпадает с визуальным (2.4.3); положительный `tabIndex` не используется.
- Ссылка «к содержимому» первой в порядке фокуса, когда перед содержимым меню.

## Шаблоны виджетов — WAI-ARIA APG, реализация из библиотеки

| Виджет в студии | Шаблон | Что обязано работать |
|---|---|---|
| модалки создания, карточка видео | Dialog (modal) | роль и имя, фокус внутрь, `Escape`, возврат фокуса к открывшему, фон инертен |
| вкладки канала и видео-проекта | Tabs | `tablist`/`tab`/`tabpanel`, стрелки между вкладками, `Tab` — в панель |
| выдвижное меню навигации | Disclosure / Dialog | `aria-expanded` на кнопке, закрытие `Escape` |
| меню «ещё» на карточке | Menu Button | стрелки, `Escape`, возврат фокуса |
| подсказка | Tooltip | появляется и по фокусу, не только по наведению |

Реализация — нативный `<dialog>` с `showModal()` (инертный фон и `Escape` даёт браузер) либо
библиотека примитивов без стилей (React Aria — Apache-2.0, Radix — MIT); выбор — решение
`dependency-hygiene`. Самописная фокус-ловушка — ровно то, от чего предостерегает ось 1a
`code-quality`: краевых случаев у неё больше, чем кажется.

## Цвет и контраст

- Текст — не ниже 4.5:1 к фону, крупный текст (от 24 px или 18.66 px жирным) — 3:1 (1.4.3) <!-- снимок ок: внешний порог WCAG 2.2 1.4.3 -->.
- Границы полей, иконки-кнопки, кольцо фокуса — 3:1 к соседнему цвету (1.4.11) <!-- снимок ок: внешний порог WCAG 2.2 1.4.11 -->.
- **Контраст — свойство ПАРЫ токенов**, поэтому проверяется по объявлению, а не по экрану: пара,
  прошедшая один раз, проходит везде, где её используют. Слабая пара годится только для крупного
  текста или декора, и это решение записывается рядом с токеном.
- Цвет не единственный носитель смысла (1.4.1): статус «отклонено» — ещё и словом или значком;
  свой/чужой канал — ещё и подписью для скринридера.

## Формы

- У каждого поля видимая подпись, связанная с полем (`label`/`htmlFor`) — плейсхолдер не подпись
  (1.3.1, 3.3.2).
- Ошибка поля — текстом у поля, связана через `aria-describedby`, поле помечено `aria-invalid`
  (3.3.1); отказ сервера по полю доезжает туда же (домен `студия-создание`, Сз2).
- Обязательность — атрибутом `required`, а не только звёздочкой.

## Динамика и статус

- Сообщение без переноса фокуса («сохранено», «рендер идёт», «не удалось — код реакции») —
  `role="status"` (вежливо) или `role="alert"` (срочно) (4.1.3).
- Содержимое, появляющееся по наведению или фокусу, закрывается `Escape` и не исчезает, пока на
  него наведён указатель (1.4.13).
- Иконка-кнопка без текста — с `aria-label`; сама иконка — `aria-hidden`, иначе скринридер
  читает имя файла значка. Проверять по DOM, а не по памяти о поведении библиотеки иконок.

## Движение

- `prefers-reduced-motion`: подъёмы карточек, масштаб миниатюр, анимации входа — под
  `motion-safe:`; при `motion-reduce:` — мгновенно или только прозрачностью (2.3.3).
- Ничего не мигает чаще трёх раз в секунду (2.3.1) <!-- снимок ок: внешний порог WCAG 2.3.1 -->.

## Графики

График статистики (удержание, рост) дублируется таблицей значений или текстовым итогом; серии
различимы не только цветом (штрих, подпись). Цвета серий и форма графика — скил `dataviz`.

## Как проверять

1. **Автоматика** — `@axe-core/playwright` (MPL-2.0) в том же прогоне, что геометрия: по
   `[data-component]` на каждой ширине матрицы. Ловит только часть нарушений — чистый отчёт `axe`
   не значит «доступно».
2. **Клавиатура руками** — пройти экран только `Tab`/`Shift+Tab`/`Enter`/`Escape`/стрелками:
   дошёл ли до каждого действия, видел ли фокус, вернулся ли фокус после модалки.
3. **Скринридер** перед выпуском экрана — NVDA с Firefox или Chrome, VoiceOver с Safari:
   объявляется ли имя, роль и состояние каждого элемента управления.
